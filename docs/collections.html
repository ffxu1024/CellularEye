Trajectory and direction conventions

Traj-1-1-2025 and Traj-1-1-202609 are recording IDs for the same geometric trajectory, shown here as Traj-1-1. Original IDs are retained in CSV and JSON. Go → Back denotes both flight directions within one collection. Collection IDs are not presented as UTC measurement timestamps; use the individual file timestamps for alignment.
