CELLULAREYE TOOLKIT

Download the data

Raw measurements — ScienceDB

Open the published ScienceDB dataset

ScienceDB is the primary distribution point for the released CellularEye collections. Use the dataset record to select and download raw measurements and associated records. The release contains approximately 2.68 TB before compression; the size of individual downloads depends on the selected archive.

DOI: 10.57760/sciencedb.018bv · CSTR: 31253.11.sciencedb.018bv

Ready-to-use detection benchmark

Download benchmark v1.0

The approximately 586 MB archive contains measured RD images, YOLO labels, fixed splits, and scenario metadata. It has 224 training, 71 validation, and 1,141 test images and requires no raw binary recordings. See the benchmark guide for extraction and reading commands.

Auxiliary portal — PML

The PML multimodal data portal provides an additional dataset information and access entry point. ScienceDB is the main source for this release.
