# Detection experiments

Tools for fixed-source YOLO26n training, measured-scenario evaluation, complex-input CFAR, and numerical plots.

See the [experiment guide](https://ffxu1024.github.io/CellularEye/experiments.html) for installation, data downloads, commands, coordinate conventions, and metric definitions.

`configs/` stores the four training configurations and the exact measured test membership. `results/` stores archived training histories, per-seed detector outputs, per-frame localization errors, and the numerical sources used by the plotting command. Training images are distributed as a Release asset. Code is MIT; released images, annotations, and result data are CC BY 4.0. Ultralytics and pretrained weights retain their upstream licensing.
